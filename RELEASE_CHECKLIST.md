# Public Release Checklist

Complete every item before making the repository or archive public.

- [ ] Replace `SOC Dataset Contributors` in `CITATION.cff` and `LICENSE.md` with the named legal rights holder(s).
- [ ] Add a maintainer contact address and the final repository URL to `CITATION.cff`.
- [ ] Confirm that the institution and all contributors authorize public release under CC BY 4.0.
- [ ] Confirm that no equipment-vendor export restriction, confidentiality obligation, or third-party driving-cycle right prevents release.
- [ ] Confirm that no personally identifying, location, serial-number, or proprietary laboratory information remains in CSV files or public metadata.
- [ ] Validate `dataset_manifest.csv` and `SHA256SUMS.txt` against the final archive.
- [ ] Create a versioned archive release and record its DOI or permanent URL in `CITATION.cff`.
- [ ] Tag the corresponding code repository with the same dataset version.
- [ ] Publish a clear change log entry for every later correction, withdrawal, or extension.

## Citation format before an article exists

`SOC Dataset Contributors. (2026). Temperature-Aware SOC Estimation Dataset (Version 0.1.0) [Data set]. Permanent archive URL or DOI.`

After an article is published, retain this dataset citation and add the article citation separately.
